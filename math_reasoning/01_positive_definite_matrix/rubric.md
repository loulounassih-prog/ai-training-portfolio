# Positive Definite Matrix — Rubric

**Total: 10 points**

| Criterion | Maximum |
|---|---:|
| Correct conclusion | 1 |
| Correct use of positive definiteness | 3 |
| Valid eigenpair argument | 3 |
| Valid positivity conclusion | 2 |
| Clarity and rigor | 1 |
| **Total** | **10** |

## 1. Correct Conclusion — 1 Point

- **1 point:** States that every eigenvalue is strictly positive.
- **0 points:** Gives an incorrect or missing conclusion.

## 2. Correct Use of Positive Definiteness — 3 Points

- **3 points:** Correctly applies $v^T A v>0$ to a nonzero vector relevant to the proof.
- **2 points:** Uses the quadratic-form definition correctly but does not fully connect it to an eigenvector.
- **1 point:** Mentions the correct definition without using it effectively.
- **0 points:** Replaces positive definiteness with a false property such as entrywise positivity.

## 3. Valid Eigenpair Argument — 3 Points

- **3 points:** Introduces $Av=\lambda v$ with $v\neq 0$ and correctly derives $v^T A v=\lambda v^T v$ or an equivalent identity.
- **2 points:** Uses an eigenpair correctly but omits a minor algebraic step.
- **1 point:** Refers to eigenvectors or the Rayleigh quotient but leaves a substantial gap.
- **0 points:** Gives no valid connection between the quadratic form and an eigenvalue.

## 4. Valid Positivity Conclusion — 2 Points

- **2 points:** Uses $v^T v=\|v\|^2>0$ to conclude rigorously that $\lambda>0$.
- **1 point:** Reaches the conclusion with a minor omitted justification.
- **0 points:** Uses an invalid positivity argument.

## 5. Clarity and Rigor — 1 Point

- **1 point:** The response is concise, readable, and mathematically unambiguous.
- **0 points:** The response is materially unclear or relies on undefined claims.

A mathematically equivalent rigorous proof, including one based on the Rayleigh quotient or the spectral theorem, receives full credit for the corresponding criteria. The response need not reproduce the reference solution's wording.
